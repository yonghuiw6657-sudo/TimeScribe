TimeScribe · 使用说明
========================

这是一个只在你电脑上运行的小工具，用来记录你在每件事（项目）上投入了多少时间。
不需要安装、不需要联网、不需要登录，数据存在你自己的电脑里。


一、怎么打开
------------

双击文件夹里的「启动.bat」。

等一两秒，Microsoft Edge 会自动打开这个应用。如果浏览器窗口没有自动跳出来，
就手动打开 Edge，在地址栏输入：http://127.0.0.1:8787/

用完之后可以直接关掉浏览器窗口，数据不会丢。
后台会留一个小程序（负责把页面提供给你的浏览器），这很正常。
如果你想彻底关掉它，双击「停止.bat」即可。


二、最常用的操作
----------------

· 新建项目：点右上角的「＋ 新建项目」，填个名字（比如"工作"、"学英语"）。
· 开始计时：在项目卡片上点「开始」，右边的秒表就开始走了。
· 中途被打断：点「暂停」，回来点「继续」。暂停的时间不算投入。
· 做完了：点「停止」，这一段就会被记录下来。
· 换一件事做：直接点另一个项目的「开始」，前一个会自动停下并记录。
· 点错了：停止后屏幕下方会出现提示条，点「撤销」就能取消刚才那一段。
· 想边干别的边计时：直接切走就行（切标签、切窗口、最小化都不会停）。
  只有关掉浏览器或关掉这个应用，那一段才会结束并保存。

子项目：展开一个项目（点左边的三角），点「＋ 新建子项目」。
子项目可以单独计时，它的时间会自动算进父项目的总投入里。
子项目下面不能再建子项目，这是有意设计的（避免层级太深看不清）。


三、几个会自动生效的规则
------------------------

1. 同一时刻只有一个计时器在跑。点别的项目「开始」，原来那个会自动停。

2. 单次实际投入不足 2 分钟，这一段会被丢掉、不记录。
   （这是为了避免手滑点出来的几秒钟碎片污染数据）
   这个 2 分钟可以在「设置」里改。

3. 切走浏览器（切标签、切到别的窗口、最小化）不算中断。
   计时照常在后台走，切回来数字是连续的，不会少算。

4. 计时中关掉浏览器（或关掉这个应用、关机）：那一段就**直接结束**了，
   并且只算到你关闭的那一刻（不会把关机那几个小时算进去）。
   如果这一段的实际投入够了时长（默认 2 分钟），会自动保存成一条记录；
   不够就直接丢掉，不留半截。

5. 万一浏览器是被强行结束的（任务管理器里结束进程、或者电脑突然断电），
   下次打开时程序会按"最后一次记录的进度"把那一段结算并保存，不会凭空多出时间。

6. 专注度 = 实际投入 ÷（实际投入 + 暂停）。
   每段计时各有一个百分比，项目卡片上还有一个"整体专注度"。

7. 忘了开计时？打开项目明细（项目卡片上的「⋯」→「查看时间明细」），
   点「＋ 手动补一条」可以补录。补录不受 2 分钟限制。


四、备份（很重要，请偶尔做一次）
--------------------------------

点右上角的「导出」，会下载一个类似这样的文件：
    TimeScribe-2025-06-11-1405.json

建议把它保存到本文件夹里的「备份」子文件夹，或者任何你记得住的地方。

为什么必须做这件事：
    数据存在浏览器（Edge）里。如果你用清理软件清理浏览器数据，
    或者手动清了 Edge 的浏览数据，这些记录会一起被删掉，而且找不回来。
    有了导出的文件，就能随时恢复。

建议：每隔一两周，或者在做重要记录之后，点一次「导出」。


五、恢复数据
------------

点右上角的「导入」，选择你之前导出的 json 文件。
导入会覆盖当前的全部数据，所以会先弹一个确认框（写清楚里面有多少项目和记录），
而且在覆盖之前，程序会自动把当前数据备份一份。
如果不小心导错了，导入完成后马上点提示条上的「撤销」，就能退回导入前的数据。


六、换电脑怎么搬
----------------

1. 在旧电脑上点「导出」，把 json 文件拷到新电脑（U盘、网盘都行）。
2. 把整个「TimeScribe」文件夹也拷过去。
3. 在新电脑上双击「启动.bat」。
4. 点「导入」，选那个 json 文件。


七、千万不要做的两件事
----------------------

1. 不要用清理软件（或 Edge 的"清除浏览数据"）清理这个电脑的浏览器数据，
   否则记录会消失。要做清理之前，先「导出」一次。

2. 不要换浏览器打开。数据是存在浏览器里的：
   用 Edge 打开的是一份数据，换 Chrome 打开会是空的，那不是数据丢了，
   而是看到了另一份存储。请一直用 Edge（「启动.bat」就是帮你用 Edge 打开的）。


八、文件说明
------------

启动.bat          双击这个来打开应用
停止.bat          万一后台的小程序没退出，双击它关掉
launch.ps1        启动逻辑（供 启动.bat 调用）
serve.ps1         本机的小型网页服务（只监听 127.0.0.1，不对外开放）
start-server.ps1  负责在后台把服务拉起来
index.html        应用页面
css\  js\         应用的样式和逻辑
tests\            自检用的测试（想验证功能是否正常可以双击 测试.bat）
测试.bat          跑一遍全部自检，结果显示在窗口里
说明.txt          本文件


九、常见问题
------------

问：双击「启动.bat」没反应？
答：看看文件夹里有没有 server.log，里面会写明原因。
    最常见的是 8787 端口被别的程序占用了，可以先双击「停止.bat」再试。

问：浏览器提示"无法访问此网站"？
答：说明后台的小程序没起来。双击「停止.bat」，再双击「启动.bat」。

问：我记录的某一段不对，能改吗？
答：能。项目卡片上的「⋯」→「查看时间明细」，每条记录后面有「改」和「删」。

问：不小心删了项目怎么办？
答：删项目会连记录一起删掉，找不回来（所以删除前会弹确认框）。
    如果之前导出过备份，可以「导入」那个文件恢复到导出时的样子。

问：数据会同步到手机或其他电脑吗？
答：不会。这个工具只在本机运行，没有联网功能。想搬到别的电脑就用「导出/导入」。
